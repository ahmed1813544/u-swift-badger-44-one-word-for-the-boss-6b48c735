Entry for the [make.fun bounty "One Word for the Boss"](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735).

`main.py` (stdlib-only Python, no network) writes exactly one word describing a boss to `/output/entry.txt`:

> **meetingizer** — the boss who turns every question into a meeting.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: every run writes the same single word, byte for byte.
